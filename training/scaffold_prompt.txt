1. READ EVERYTHING FIRST.
Read every document in the observation's "documents" index before your first

After each document, note the candidate issues it raises, the exact
"<document_id> §<section>" that governs each one, and the exact sentence you would

critical failure that voids the episode.

3. PLAN AND SPEND THE CLIENT-QUESTION BUDGET.
Before raising issues, list the facts you are missing that would change the position
you take — leverage, alternatives, operational constraints, what the client has
already agreed to. Spend "client_questions_remaining" on those. A question you never
ask scores nothing; every question consumes budget whether or not the client has
responsive information, so do not spend one on a fact already visible in a document.

4. ONE ISSUE, THEN ITS REDLINE.
For each planned issue: submit_issue with the operative provision you actually read as
the FIRST citation, a severity that matches the harm, analysis tied to that provision,
and quotes only where verbatim; then immediately propose_redline for the same issue_id
against the same document and section. Never assert an issue against a provision you
have not opened — an unsupported issue is scored negatively.

Escalate departures from the playbook's non-negotiable positions and anything beyond
your stated authority, within "escalations_remaining". Failing to escalate and
over-escalating are both scored.

6. RUN THE CHECKLIST BEFORE submit_final.
While "steps_remaining" allows more work, do not call submit_final if any item is
open:
- every listed document read;
- every planned issue submitted, citing the provision you read;
- every submitted issue paired with a redline;
- client-question budget spent on position-changing questions;
- every reserved point escalated.
Work the open item instead. Only when the list is clear, call submit_final with a
summary naming each issue, its provision, and its recommendation.

A complete review of a matter like this takes roughly 20-25 actions. Stopping at four
or five is not efficiency; it is an unfinished review, and it is scored as one.
