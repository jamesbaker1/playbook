# Progress record — August 6–7, 2026

*A dated snapshot of what shipped in the two-day sprint from "unmeasured
environment with a plan" to "measured benchmark with a preregistered training
program." Written for anyone (including future us) reconstructing what
happened and why. Ledger context: `docs/plan-2026-08.md`; forward plan:
`docs/playbook-1-plan.md`.*

## Shipped

**v0.4.0 released** (tag + GitHub release, commit `8bfd4e2`): the first
release with measured model baselines. PyPI publication deliberately skipped
this release.

**First measured baselines** (`results/v0.4.0/`, `docs/baseline-report.md`):
Qwen2.5-7B/14B on three seeds, 32B on one, all 12 public matters, native tool
calling against vLLM-on-Modal (`training/modal_vllm.py`, new). Expert
reference replay 0.985. Headline findings, all replayable:

- Best model score 0.165 (14B); no model asked useful client questions
  (question recall ≤ 0.02 vs 0.958 for the reference).
- Critical-failure rate rose with scale: 5.6% → 13.9% → 25.0%.
- Failure archetypes: unauthorized concession on the buyer-side M&A matter in
  5 of 7 runs across all models; every fabricated quotation (3) occurred in
  episodes of ≤ 6 steps; one accepted trap counter under negotiation pressure.

**Variant family catalog scaled 5 → 12 families / 14 → 42 variants** — every
public matter now backs a replay-verified training family (references ≥ 0.9,
29 adversarial gates firing, byte-deterministic builds), covering all eight
variation dimensions.

**Sealed evaluation corpus at 11 families** (private repository): 6
owner-reviewed + 5 model-drafted pending owner review (review is what clears
the 10-family evaluation floor). All 11 verified against the committed engine.
Corpus-wide hash integrity hardened (`.gitattributes` line-ending fix — CRLF
normalization would have silently broken every sealed digest on fresh clones).

**`playbook-critic` shipped** (commit `c16a45d`): deterministic verification
of proposed deal-review work using only client-visible materials — verbatim
quote verification, citation resolution, prohibited-concession detection
against a client-authored authority file (`playbook.authority.v1`). Enforced
answer-key firewall (never reads rubric/hidden-facts/counterparty; tested
structurally). Adversarially hardened: 16 defects found and fixed, each
mutation-checked against a named test. See `docs/critic.md`.

**Rollout-yield pilot ran** (Workstream 4 validation, ~$0.31 of GPU time):
generate → filter → replay-verify → dataset-build pipeline works end to end.
Decisive negative: Qwen2.5-32B rejected as teacher (0/8 candidates above a
0.5 score bar; mechanical filters alone admit negative-raw-reward
trajectories, so a preregistered minimum-score filter is now required —
folded into the plan).

**Playbook-1 experiment contract hardened and partially executed**
(`docs/playbook-1-experiment.yaml`): CI-based preregistered decision rule
(one-sided 95% family-clustered bootstrap), state-action-vs-base secondary
comparison, per-condition protocol-failure reporting, temptation-density
requirement, eval-contamination rule (sealed families cannot derive from
public matters), reviewer-hours budgeting. Owner approvals recorded:
**student = Qwen2.5-14B-Instruct** (2026-08-06); teacher remains open after
the 32B rejection.

**Launch post pre-written** (working-backwards): the Playbook-1 release post
exists in full with preregistered result placeholders the frozen gates must
fill; it publishes only if the claim holds. Held privately until then.

**Positioning study completed** (held privately): closest analogs identified
and ranked; the combination Playbook occupies — live deterministic
counterparty, deterministic critical-failure gates, replay verification,
budgeted client interaction, RL trainability — was found in no existing
system, while each individual component has precedent. Conclusions inform the
plan but are not published here.

## Infrastructure hardening (paid for in real money)

- **Bench checkpointing** (`fe355cb`): every episode now lands in
  `<out>.partial.json` immediately; interrupted sweeps resume instead of
  repaying. Motivated by two interrupted API sweeps that billed ~$7.73 for
  episodes that never reached disk.
- **`--max-tokens` cap** in the baseline runner: metered gateways
  pre-authorize the model's full output window per request when uncapped, and
  concurrent sweeps starve each other's reservations. Run metered sweeps
  sequentially, capped.
- **CI restored to green**: stale Worker vendor bundle re-synced; isort
  misclassification fixed (the repo's `datasets/` directory shadowed the
  HuggingFace package name).
- Suite grew 260 → 304 tests across the sprint; green throughout.

## The through-line

The benchmark measures everyone (open models, frontier references, eventually
humans); the critic deploys the benchmark's gates without the answer key; the
sealed corpus makes evaluation claims possible; and Playbook-1 is the
preregistered demonstration that training inside the environment improves
professional judgment. One codebase, one verification spine.
